# Code of Conduct

## The short version

Be decent. Assume good faith. Criticise code, not people.

## In practice

**Expected:** clear, specific, technical communication. Say what broke, what you
observed, and what you expected. Disagreement about a design decision is
welcome and useful — this project changed shape several times because someone
pushed back on a bad idea.

**Not acceptable:** personal attacks, harassment, demeaning or discriminatory
remarks, sustained disruption, publishing others' private information, or
sexualised language and imagery.

This applies in issues, pull requests, commit messages, and any other project
space.

## Scope and enforcement

The maintainer may edit, hide, or delete contributions that violate this, and
may block accounts that do so repeatedly or seriously.

Report a problem through GitHub's private vulnerability reporting (Security →
Report a vulnerability), which reaches the maintainer privately and is a
reasonable channel for conduct issues too. Reports will be handled discreetly.
